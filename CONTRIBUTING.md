# Contributing

Thanks for helping improve AIRMN's public resources.

## Ways to contribute

- Suggest a useful research resource.
- Report a broken or outdated link.
- Improve wording, organization, or accessibility.
- Propose a new section when the current categories do not fit.

## Resource suggestions

A good resource should be:

- Useful to researchers, students, engineers, founders, or practitioners in AI and related fields.
- Stable enough to remain useful over time.
- Clearly described, including who it is for and why it matters.
- Free, open, or clearly labeled if access is limited.

For resource suggestions, open an issue with:

1. Resource name
2. URL
3. Intended audience
4. One sentence explaining the value

## Pull requests

Keep pull requests focused. For a resource change, explain what changed and why. For wording changes, keep the tone clear and direct.

Do not submit secrets, private Discord content, personal data, confidential research material, or copyrighted material that you do not have permission to share.
